# Stage Data Analyst — projet accompagné

Demande corrigée : apprendre le travail de stagiaire dans un dossier métier continu, avec les fondamentaux expliqués au moment de leur utilisation. Aucun découpage scolaire par outils.

Projet : piloter l’activité maintenance à partir d’un lot synthétique imparfait. Quatre demandes du responsable, quarante actions : fiabiliser le reçu ; livrer un bilan mensuel ; expliquer les écarts et recommander ; transmettre un suivi actualisable.

Réalisé : espace Stages, dossier Data distinct du CV, données reproductibles, demandes et livrables, raisonnement guidé, code, travail personnel, contrôles, solutions commentées, dépannage, journal et revue avec preuves. Sauvegarde privée séparée, export/import contrôlé et protection des conflits.

Validation : tests frontend et Worker, régression du préparateur, contrôle syntaxique Python et exécution SQL ; revue des conversions, périmètres et preuves de réconciliation. Les sorties natives Excel et Power BI doivent être produites et examinées pendant le travail accompagné.
