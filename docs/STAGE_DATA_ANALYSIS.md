# Stage Data Analyst : piloter l’activité maintenance

Ouvrir Stages puis Data Analysis. Le dossier est indépendant du stage Computer Vision.

Le responsable demande un bilan fiable sur les coûts, arrêts et interventions ouvertes. Le même dossier synthétique accompagne quatre demandes de travail et quarante actions. Les fondamentaux apparaissent dans les tâches, avec raisonnement, code guidé, essai personnel, contrôles, correction et revue.

Télécharger le préparateur depuis Le projet et exécuter `python starter_data_analysis.py --output data` dans un dossier neuf. Les CSV, SQLite et le dictionnaire sont générés localement. Conserver le reçu imparfait ; les corrections exigent la réponse simulée du propriétaire. Les blancs ne sont pas des zéros.

Consigner son travail, son fichier et ses difficultés, puis copier le point pour l’encadrant dans la conversation. La progression distingue livrables prêts et travaux revus avec preuves. Le système ne certifie pas automatiquement le code ou les compétences.

La sauvegarde authentifiée utilise Formation_Data_Analysis/progression.json dans l’archive privée existante. Le CV conserve Formation_CV/progression.json. Le brouillon local et l’export permettent de récupérer son travail ; une révision distante modifiée bloque l’écrasement.

Excel ou un tableur compatible et Power BI Desktop sont requis pour les livrables correspondants. Les tests automatiques couvrent l’application, le préparateur et SQL, pas l’exécution native Excel/Power BI. La remise finale exige un véritable export Excel réconcilié et conserve les empreintes des sources.
